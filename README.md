# AI Lab PWA

A phone-ready Progressive Web App prototype for the self-improving AI project.

## iPhone installation

A PWA must be served from HTTPS (or localhost during development). After hosting these files on an HTTPS site:

1. Open the site in Safari on iPhone.
2. Tap Share.
3. Tap **Add to Home Screen**.
4. Open **AI Lab** from the Home Screen.

## Important

This package is a front-end demo. It does not contain an API key and does not call a real AI model. To connect a model, add a secure backend endpoint. Do not put a private API key directly in the PWA.

The self-improvement concept should keep generated experiments sandboxed and require approval before changing the active agent.
